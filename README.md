### 🚀 Featured Project

#### [Playwright + pytest QA Framework](https://github.com/NimeshaDev/playwright-pytest-qa-framework)

An end-to-end test automation framework built with Python, Playwright and pytest.

- **UI automation** with the Page Object Model (login, cart and full shopping flow on saucedemo.com)
- **API testing** with `requests` - GET, POST, 200/201/404 checks
- **BDD scenarios** written in Gherkin with `pytest-bdd`
- **CI/CD** - tests run automatically on every push via GitHub Actions
